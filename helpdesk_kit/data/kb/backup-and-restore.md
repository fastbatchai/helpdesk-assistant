# Backup and Restore

What we can bring back depends on where the file was saved.

## What is backed up

| Location | Backup | Restore window |
|----------|--------|----------------|
| Personal backup folder (NorthBackup) | Continuous | 90 days |
| Shared drives (N:) | Daily, at night | 30 days |
| Email and calendar | Continuous | 14 days |
| Teams chat | Not restorable | None |
| Laptop desktop and downloads | Not backed up | None |

Save your work in the personal backup folder or on a shared drive. Files that are saved only to the desktop or downloads folder are lost if the laptop fails.

## Restore a file yourself

**Personal backup folder:** right-click the file or folder, choose Version History, and pick a version. For a deleted file, open the NorthBackup web page and look in Recycle Bin.

**Shared drive:** right-click the folder that held the file, choose Properties, then Previous Versions. Pick the date you want and copy the file back. You will only see versions of folders you can access.

**Email:** in Outlook, open Deleted Items and choose Recover Items Deleted From This Folder.

## When to ask the help desk

Open a ticket if:

- the file is older than the self-service windows allow, because archives may still have it
- a whole folder or mailbox has to be restored
- you are unsure which version you need

Give the full path, the file name and the last date the file was correct. Restores usually take one business day, or longer for archive requests.

## Ransomware and malware

If files suddenly appear scrambled or renamed, or a ransom message appears, do not try to restore anything yourself. Disconnect from the network, leave the laptop switched on, and phone the help desk on extension 4357 immediately. This is a security incident. Restoring too early can overwrite the evidence or spread the damage.

## Restore tests

IT Infrastructure tests restores from every backup system each quarter.
