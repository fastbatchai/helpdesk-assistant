# Admin Rights Policy

Nobody at Northgate has permanent admin rights on their laptop. Most attacks need admin rights in order to spread, so keeping them temporary reduces the risk for everyone.

## You probably do not need them

Most software installs from Company Apps without any admin rights. Printer setup, VPN updates and operating system updates also run without them. Try those routes first.

## Temporary admin rights

If you really need them, for instance to install approved software that is not in Company Apps or to test a driver, use AdminNow:

1. Open AdminNow from the Start menu.
2. Give your reason and the software or task concerned.
3. Your manager receives the request and approves it.
4. You get admin rights for eight hours, then they are removed automatically.

Everything done during that time is logged. People in engineering roles may approve their own requests up to twice a month, and any further requests go to their manager.

## Developers and engineers

If your role involves regular admin tasks, ask for a developer workstation profile through the portal. It allows containers and local development tools without full admin rights. IT Security reviews these requests, which take about five business days.

## What you must not do

While you have admin rights, you must not:

- install anything that is not approved
- turn off antivirus, disk encryption, or device management
- create extra local accounts
- share your session with anyone

Breaking these rules leads to the rights being withdrawn, and the case may be referred to your manager.

## Server and system administrators

Server and cloud administrators use separate admin accounts, and these are never used for email or browsing. These accounts must use a hardware security key for MFA, and are reviewed each quarter.

## Questions

Software approval is a separate process. See the Software Request Process and the Approved Software List. The help desk cannot grant admin rights over the phone, even in urgent cases, without manager approval.
