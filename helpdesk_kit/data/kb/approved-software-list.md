# Approved Software List

This list covers the software approved for company laptops. Anything marked Company Apps can be installed by yourself. Anything marked Request needs a Software Request in the portal.

## Productivity

- Microsoft 365 (Word, Excel, PowerPoint, Outlook, Teams): pre-installed
- Adobe Acrobat Reader: Company Apps
- Adobe Acrobat Pro: Request, manager approval needed
- 7-Zip: Company Apps
- Notepad++: Company Apps

## Communication

- Microsoft Teams: the only approved tool for internal meetings and chat
- Zoom client: Company Apps, for joining external meetings only

## Design and data

- Figma: Request
- Power BI Desktop: Company Apps
- Tableau Desktop: Request, manager approval needed
- R and RStudio: Company Apps

## Engineering

- Visual Studio Code: Company Apps
- Git: Company Apps
- Python: Company Apps
- Docker Desktop: Request, engineering roles only
- PuTTY: Company Apps

## Security and access

- NorthLink VPN: pre-installed
- NorthKey Authenticator: phone app store
- Northgate Password Vault: pre-installed. This is the only approved password manager.

## Not allowed

These are not approved, and any installation will be removed:

- personal cloud storage clients
- remote-control tools that let someone outside the company operate your laptop
- peer-to-peer file sharing software
- unlicensed or cracked software of any kind

## Keeping this list current

IT Security reviews this list every quarter. Software that no longer gets security updates is removed, and people using it are told in advance. To request an addition, follow the Software Request Process.
