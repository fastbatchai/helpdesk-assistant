# Software Request Process

Do not install software from the internet on a company laptop. Most laptops will block the installation, and unapproved software can put company data at risk.

## Step 1: check Company Apps

Open Company Apps on your laptop. Anything listed there has already been approved and is free to install, without needing a ticket.

## Step 2: check the Approved Software List

Some approved software is licensed per person and so is not in Company Apps. If it is on the Approved Software List, open a Software Request in the portal. These requests are normally fulfilled within one business day.

If the licence costs more than 200 euros per year, your manager must approve it. The portal will send them the request automatically.

## Step 3: request something new

If the software is not on the list, open a New Software Request and include:

- the name, vendor and version
- what you need it for, and whether an approved tool could do the job
- the type of data it will touch, using the Data Classification levels
- how many people need it

IT Security then carries out a review, which takes about 10 business days. Software that handles Confidential or Restricted data may take longer because it also needs a Legal review.

## Possible outcomes

- **Approved:** it is added to the Approved Software List and we install it.
- **Approved with limits:** for instance, allowed only for Public data.
- **Declined:** we explain why and suggest an alternative.

## Browser extensions and AI tools

Browser extensions and online AI tools follow the same process, even when free. Do not paste Confidential or Restricted data into any tool that is not on the approved list.

Installing approved software sometimes needs admin rights. See the Admin Rights Policy.
